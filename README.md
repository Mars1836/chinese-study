# chinese-study

Ứng dụng web học tiếng Trung tương tác hiện đại (Giáo trình Hán Ngữ 1 - Bài 1 đến Bài 5).

## Tính năng nổi bật

1. **Ngữ âm Pinyin:** 
   - Thanh mẫu, vận mẫu (vận mẫu đơn, kép, mũi).
   - Mô phỏng giấy bay cho các âm bật hơi.
   - Thẻ âm thanh trực quan hỗ trợ phát âm chuẩn.
2. **Thanh điệu & Biến điệu:** 
   - Mô phỏng 4 thanh điệu với đồ thị cao độ trực quan.
   - 4 quy tắc biến điệu quan trọng (Thanh 3 + 3, 3 + 3 + 3, Nửa thanh 3, Biến điệu chữ 不).
   - Công nghệ âm thanh kép (Dual-Engine Audio): Web Speech API + Web Audio Synth Pitch Contour.
3. **Nét chữ & Tập viết:** 
   - 8 nét cơ bản & 7 quy tắc bút thuận.
   - Bảng vẽ tập viết chữ Hán **Mễ Tự Cách (米字格)** tương tác với bút lông, độ dày nét, màu mực và hoàn tác.
4. **Từ vựng & Chiết tự bộ thủ:** 
   - Từ vựng Bài 1 đến Bài 5 đầy đủ Pinyin, Hán Việt, định nghĩa và ví dụ.
   - Chiết tự từng bộ thủ cấu tạo chữ kèm câu chuyện gợi nhớ.
   - **Modal Luyện viết chữ Hán** trực tiếp từ từng thẻ từ vựng.
5. **Hội thoại & Trắc nghiệm:** 
   - Luyện nghe và đọc theo bài khóa hội thoại tương tác.
   - Bộ câu hỏi trắc nghiệm củng cố kiến thức kèm giải thích chi tiết.

## Cài đặt & Chạy ứng dụng

```bash
cd app
npm install
npm run dev
```

Truy cập: `http://localhost:3000`
